# Projects

## uul_chat_ai — this project

An AI ops chat portfolio: recruiters and clients log in with Google and chat (text or voice) with an AI agent grounded in this knowledge base. Built with Next.js, FastAPI, a self-hosted LiteLLM gateway (OpenRouter for chat, OpenAI for STT/TTS/embeddings), and Supabase (Postgres + pgvector + Auth), deployed via Docker Compose on a self-hosted VPS.
